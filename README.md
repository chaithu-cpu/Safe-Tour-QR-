Project Overview

SAFE TOUR QR is a smart QR-code-based system designed to help identify missing persons and reunite them with their families, especially in crowded places such as temples, festivals, tourist destinations, and public events.

The system provides public registration, QR-code generation, missing-person reporting, and an authorized officials' dashboard for verification and case management. It aims to make identification faster, improve coordination, and protect sensitive personal information.
